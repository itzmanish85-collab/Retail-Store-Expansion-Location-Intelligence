# Retail Store Expansion & Location Intelligence — Complete Portfolio Project

## What is included
1. `dashboard.html` — a ready-to-open interactive business dashboard.
2. `Retail_Store_Expansion_Analytics.xlsx` — offline workbook with data, KPIs and charts.
3. `data/` — datasets used by the analysis.
4. `README.md` — project overview and interview talking points.

## Business Objective
Recommend the best markets for a retail company’s next store openings using performance, demand, competition, income, growth and cost indicators.

## Analytical Workflow
Data → Python/EDA → MySQL business analysis → KPI dashboard → opportunity scoring → expansion recommendation.

## Key deliverables
- Store performance analysis
- Regional revenue/profit analysis
- Candidate market ranking
- Opportunity score
- Executive KPI dashboard
- Expansion recommendations

## Dataset note
All data is synthetic and intended for a portfolio/college project. Do not represent it as proprietary or real company data.

## How to use
Open `dashboard.html` in Chrome/Edge/Safari. The dashboard is self-contained except for the Plotly JavaScript library loaded from its public CDN.
Open the Excel workbook for an offline version and inspect the `Dashboard` sheet.
